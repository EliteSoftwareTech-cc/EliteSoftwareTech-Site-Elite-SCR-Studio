Compile Videos, Logos & Images into Portable .SCR Executables

Elite-SCR Studio Ultimate (SCR-Maker) packages .mp4/.avi videos, bouncing images, or static slideshows together with custom .ico icons and configuration rules directly inside standalone Windows .scr screensaver binaries using native Win32 C++, Media Foundation / DirectShow, and GDI+ resource injection.

Video Playback Engine VIDEOSTUB

  • Embeds .mp4 and .avi videos directly into a redistributable .scr file.
  • Supports multi-monitor behavior (Primary, Duplicate on all, Span) and scaling modes.
  • Includes optional Mute Video Audio toggle and live in-studio previewing (F5).

Bouncing Logo Engine BOUNCESTUB

  • Emulates the classic bouncing emblem/DVD logo across monitors via GDI+.
  • Configurable independent X and Y physics speeds directly in Template Settings.
  • Supports transparent PNG and standard image formats embedded as Win32 resources.

Static / Slideshow & Stubs INJECTOR

  • Clone & resource-inject pre-compiled stub engines (VideoStub.scr, BounceStub.scr, SlideStub.scr) via Injector.cpp.
  • Optional end-user Configure dialog pass-through for runtime overrides and registry persistence.
  • Save/load reusable .escr project files with custom .ico icon injection.
